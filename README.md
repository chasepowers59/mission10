## Backend setup

The backend uses a SQLite database stored at `backend/mission10/mission10/BowlingLeague.sqlite`.

Run the backend from the project folder with:

```powershell
cd backend/mission10/mission10
dotnet run
```

Run the frontend from the `frontend` folder with:

```powershell
npm install
npm run dev
```
